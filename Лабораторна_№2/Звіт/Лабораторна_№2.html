Тема: Розробка WPF-клієнта для управління пацієнтами лікарні

Виконав: студент групи КІ-302

Куницький М.О.

Прийняв:

Іванов Ю.С.

Львів – 2026

1. Аналіз завдання та постановка задачі

Потрібно створити WPF-додаток із таблицею пацієнтів, кнопками управління та інтерфейсом для редагування даних.

Мета роботи: Розробити графічний інтерфейс та логіку керування медичними картками пацієнтів у лікарні, включаючи додавання, редагування та виписку записів.

2. Опис реалізованого рішення

Лабораторна робота присвячена розробці графічного інтерфейсу системи обліку пацієнтів лікарні. У межах завдання необхідно було створити зручну для працівників лікарні форму відображення інформації про пацієнтів, а також забезпечити можливість швидкого оновлення даних.

Для реалізації було обрано технологію WPF, що дозволяє створити інтуїтивно зрозумілий інтерфейс із таблицею RecordsGrid/DataGrid, панелями керування та діалоговими вікнами. Основна ідея полягає в тому, щоб поділити бізнес-логіку, інтерфейс та дані, використовуючи модель Patient як основу для всієї системи.

Модель Patient містить поля Id, FullName, Age, Diagnosis, Doctor, Room. Таке представлення повністю охоплює інформацію необхідну для обліку пацієнта в стаціонарі. Усі ці властивості були використані для відображення в таблиці та для форм редагування.

Для зберігання даних застосовано ObservableCollection, що забезпечує автоматичне оновлення DataGrid при додаванні, зміні або видаленні запису. Це є критично важливим для інтерактивної роботи користувача, оскільки зміни в колекції миттєво відображаються в користувацькому інтерфейсі.

Логіка кнопок додавання, редагування та виписки реалізована через окремі методи обробки подій. Для створення нового запису відкривається просте діалогове вікно, де користувач вводить дані. Для редагування вибирається поточний рядок у таблиці, після чого відкривається форма, де можна змінити значення полів. Для виписки виконується підтвердження дії перед видаленням.

Після реалізації було перевірено основні сценарії роботи: створення пацієнта, редагування даних, видалення запису, перевірка валідації та оновлення інтерфейсу після кожної зміни. Усі сценарії працювали стабільно і коректно.

3. Основні технології та архітектура

Використано платформу WPF для реалізації клієнтського інтерфейсу.

Модель даних пацієнта визначена як окремий клас із обов’язковими атрибутами.

Для оновлення інтерфейсу застосовано ObservableCollection, що забезпечує реакцію на зміни даних.

Для серверної частини використано TCP-обробку запитів і SQLite як систему зберігання даних.

Комунікація між клієнтом і сервером реалізована за допомогою JSON-структур.

4. Програмна реалізація та перевірка

Під час розробки було визначено, що система повинна бути максимально простою для користувача, але в той же час достатньо надійною для ведення медичної інформації.

Необхідно передбачити базову валідацію полів, щоб уникнути додавання записів із пустими або некоректними даними.

Важливо, щоб інтерфейс відображав актуальну інформацію у реальному часі, тому було вибрано ObservableCollection як основну структуру даних.

Після реалізації були виконані перевірки відповідності інтерфейсу, коректності логіки обробки даних і стабільності роботи базових сценаріїв. Усі основні операції виконувались у межах очікуваних результатів.

5. Результати та висновок

Лабораторна робота №2 виконана успішно. Розроблено функціональний WPF-клієнт, який дозволяє вести облік пацієнтів лікарні, управляти їхніми картками та виконувати базові операції CRUD. Реалізована система відповідає поставленому завданню та має потенціал для подальшого розвитку до повноцінної медичної інформаційної системи.
